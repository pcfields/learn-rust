# learn-rust

This repo is my sandbox for learning [Rust](https://www.rust-lang.org/). The goal is to get familiar with the language by building small programs from many sources: books, online tutorials, and my own experiments.

## Layout

Each program lives in its own folder at the top level, as an independent Cargo project (`cargo new <name>`). A program can come from anywhere; the table below records where.

| Program | Source |
| --- | --- |
| [`guessing_game`](guessing_game) | [The Rust Programming Language](https://rust-book.cs.brown.edu/), chapter 2 (Brown University interactive edition) |
| [`guest_list`](guest_list) | [Hands-On Rust](https://pragprog.com/titles/hwrust/hands-on-rust/) (Pragmatic Programmers) |

When I add a program, I add a row here.

## Notes

This is a learning repo, not production code. Expect experiments, half-finished ideas, and code that changes as I learn better approaches.
