# learn-rust

This repo is my sandbox for learning [Rust](https://www.rust-lang.org/). The goal is to get familiar with the language by working through [The Rust Programming Language](https://rust-book.cs.brown.edu/) (the Brown University interactive edition) and, over time, exploring other sources and experiments.

## Notes

This is a learning repo, not production code. Expect experiments, half-finished ideas, and code that changes as I learn better approaches.
